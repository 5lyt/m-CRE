# Data inventory

The four full input tables are under data/processed/. Their eight feature columns, order and numeric values are the supplied modeling inputs; none was recomputed. Candidate metadata under data/candidates/ contains 1,357 actual rows and a separate 1,362 requested-gene manifest. The stored pattern object is data/motifs/tfmodisco_results_1362.h5. results/revised/Data7/ contains the full feature audit, original sample manifests, pattern counts and seqlet/gene membership. results/revised/Data5/ contains cross-species metric aggregation records recovered from the public repository.

The ten-model comparison results shown in the revised Figure 2a/d are under
data/model_metrics/ten_model_controls/. The summary CSV records pooled_oof_auroc,
mean_fold_auroc, fold_std (sample standard deviation across chromosome folds) and
n_folds for all ten models (M0-M4 plus M4-T8, M4-R8, M4-P, T8-only, R8-only); the
two wide CSVs are task x model views. These historical numbers were generated by
the reviewer-response control pipeline DeepCRE_review_controls_v3, and the portable
rerun entry point is code/model/train_comparisons.py together with
code/data_deal/build_control_features.py. See
data/model_metrics/ten_model_controls/README.md for label and statistic definitions.
